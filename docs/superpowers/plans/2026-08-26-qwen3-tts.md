# Qwen3-TTS dans le serveur de transcription — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter au serveur existant une synthèse Qwen3-TTS française avec voix prédéfinies, VoiceDesign et clonage, dans le même conteneur Docker et derrière l'API OpenAI existante.

**Architecture:** FastAPI reste l'unique API publique et l'unique arbitre du GPU. Un worker Qwen isolé dans `/opt/venv-qwen` écoute un socket Unix privé ; il charge au plus un checkpoint 1.7B en BF16, tandis que l'environnement principal conserve NeMo et ses versions actuelles.

**Tech Stack:** Python 3.12, FastAPI, aiohttp sur socket Unix, Qwen3-TTS 0.1.1, PyTorch 2.11/CUDA 12.8, ffmpeg/ffprobe, Pydantic, Docker Compose, pytest.

**Spec:** `docs/superpowers/specs/2026-08-26-qwen3-tts-design.md`

## Global Constraints

- Un seul conteneur Compose et un seul port public : `127.0.0.1:8000`.
- Le worker Qwen écoute uniquement `/run/qwen-tts/worker.sock`.
- L'environnement principal et l'environnement Qwen ont des dépendances Python isolées.
- Les modèles sont `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, `Qwen/Qwen3-TTS-12Hz-1.7B-Base` et `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`.
- Un seul checkpoint Qwen est chargé en VRAM à la fois, en BF16 sur CUDA ; aucun repli CPU ou moteur alternatif.
- Toutes les opérations GPU sont sérialisées avec `AppState.gpu_lock`.
- Qwen est déchargé avant toute diarization, après le délai d'inactivité et après toute erreur CUDA/OOM.
- Le français (`fr`, traduit en `French` pour Qwen) est la langue par défaut ; `auto` doit être demandé explicitement.
- `POST /v1/audio/speech` accepte au plus 4096 caractères et les formats `wav`, `mp3`, `flac`, `opus`, `aac`, `pcm`.
- Le clonage exige `consent=true`; les références utiles durent de 3 à 30 secondes.
- Les contenus textuels, transcriptions et chemins de références vocales ne sont jamais journalisés.
- Les tests par défaut ne téléchargent aucun modèle et ne nécessitent ni torch ni GPU.
- Les 338 tests existants doivent continuer de passer sans avertissement.

```python
_QWEN_LANGUAGES = {"fr": "French", "en": "English", "auto": "Auto"}


class UnixTtsClient:
    async def synthesize(self, request: SynthesisRequest) -> SynthesisResult:
        payload = {
            "mode": request.mode.value,
            "text": request.text,
            "language": _QWEN_LANGUAGES.get(request.language, request.language),
            "speaker": request.voice,
            "instruct": request.instructions,
            "reference_audio": str(request.reference_path) if request.reference_path else None,
            "reference_text": request.reference_text,
        }
        response = await self._request("POST", "/generate", json=payload)
        if response.status != 200:
            raise self._worker_error(response.status, await response.json())
        audio = await response.read()
        if not audio:
            raise TtsUnavailableError("empty_audio", "Le worker n'a produit aucun audio.")
        return SynthesisResult(
            audio_wav=audio,
            sample_rate=int(response.headers["X-TTS-Sample-Rate"]),
            model=response.headers["X-TTS-Model"],
            load_ms=float(response.headers.get("X-TTS-Load-Ms", 0)),
            inference_ms=float(response.headers.get("X-TTS-Inference-Ms", 0)),
        )
```

Créer une session par appel avec `aiohttp.UnixConnector(path=str(self._socket_path))` et `aiohttp.ClientTimeout(total=self._timeout_s)`, puis la fermer dans `async with`. Ne jamais inclure `payload` dans les logs d'erreur.

```python
class SpeechRequest(BaseModel):
```

```python
        result = await state.tts.synthesize(build_request(body, segment, profile))
        chunks.append(result.audio_wav)
encoded = await run_in_threadpool(
    render_output, chunks, [s.pause_after_ms for s in segments],
    body.speed, body.response_format,
)
return Response(content=encoded.data, media_type=encoded.media_type)
```
